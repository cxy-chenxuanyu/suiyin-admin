## 本次采用方式

1. 两个日报入口移到聊天管理末尾，顺序企微、个微；保留旧菜单顺序、隐藏、删除、自定义名称和权限记录，并迁移原AI管理父级缓存。
2. AI提示词库与AI模型管理仍留在AI管理。两份日报模板并入现有六列表格，通过场景筛选定位；保留原型原有三条参考模板，不把成都12条真实模板复制到深圳演示数据。
3. 日报编辑器基础字段沿用现网次序；共用规则在统一列表工具栏进入。之前批准的草稿、试跑、版本发布保留为日报新增高级设置，明确静态演示及生效语义。
4. 模板与模型页引用同一份本地合成配置目录。只允许启用且匹配场景的候选；留空使用场景默认，但试跑和新批次必须解析并冻结最终配置，配置不可用则阻断。
5. 企业模型页保持只读。新增日报支持只以合成配置演示，实际还需平台注册场景并配置支持范围；无密钥、接口或平台配置编辑权限扩张。
6. 现网沟通进度05:30保持为独立事实；新日报04:00启动、08:00前目标继续按批准SPEC单独设计，真实功能阶段验证。

原型数据、试跑、发布及模型关联均为本地合成状态，不是线上设置变更。完整实现与当前验收结果见同目录 README 及 JSON 记录。
