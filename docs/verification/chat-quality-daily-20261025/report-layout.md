# 深圳日报原型版式迭代 · 2026-10-25

沿用 SPEC-SUIYIN-ADMIN-092 已批准的企微、个微独立日报与提示词管理范围。本轮为用户截图驱动的本地视觉迭代，API 配置继续暂缓。

## 本轮实现

- 两个日报不再插入“深圳本地功能验证”面板，也不从日报触发本地 health/config/runs 请求。
- 从用户提供的南京日报 HTML 迁移版心、七页签、六指标卡、洞察卡片、意向五卡与分组名单、维度表、排行条及密集表格的样式；1180px 版心、22/18/60px 留白、12px 卡片圆角和 13px 表格字号保留。主色改用管理页青绿，风险红橙保留。
- 日期保留在标题，工作号／事发接待／版本筛选收进右上角折叠入口；来源与分析说明收进页尾。两个日报继续位于聊天管理。
- 四份深圳保存报告使用同一呈现模块；按筛选后的会话聚合。使用既有人设工作号、客户名称和原文，未修改分析输入或结论。
- 同文案问题按覆盖会话展示，原文跳转验证 issue 与 occurrence 的关联，并使用对应消息证据。证据不足独立计数；未知责任身份、红线认定和失职收尾保持未知。
