# 管理页扫街人列表与十秒轨迹回放

## 1. 审核摘要

- **用户问题**：管理者要了解扫街人员在指定日期内走过哪些地方，以及行程先后；日期跨度变长时仍需要快速看完。
- **完成后变化**：在「数据展示 → 拉新记录」下面进入「扫街轨迹」，看到扫街人列表；每行点「轨迹展示」，选择日期范围，在地图上动态看完该人的全部有效行程，单次总回放不超过10秒。
- **本次范围**：现有 Admin 的人员列表、日期范围、地图大弹窗、一次自动回放与重新播放、分段及空错状态；菜单管理同步登记；纯本地演示。
- **明确不做**：在本工作区实现真实位置采集或上报、手机权限弹窗、人员角色分配界面、实时追踪或生产代码。用户现已授权完整推送及工程建单。
- **需要房总拍板**：无；Q001租户与可见范围、Q002默认交互已由房总「按这个做」批准。
- **AI 新提案**：无待决提案；已批准的交互细则保持，租户范围以E009最新明确指令为准。
- **批准与修订**：2026-10-12「按这个做」批准交互；同日「完整推送，并给王梓先建立issue实现，提出人谢东华，提出环境深圳艺星，适用环境所以医美租户」将范围修订为所有医美租户，并授权发布和工程交付。1.0.0的15租户覆盖已被此明确范围取代。

## 2. 用户问题与预期结果

### 2.1 用户与场景

管理者在后台检查某个扫街人员一天或多天的行动记录。截图显示艺星医美深圳管理页的「数据展示 → 拉新记录」，尚没有本次轨迹入口。

### 2.2 用户问题

只有拉新记录不能直接表达人员走过的地点和先后顺序；逐天翻看或按实际耗时回放无法快速看完长日期范围。

### 2.3 完成后用户能感受到的变化

找到一个扫街人，选择需要查看的日期，一次就能在地图上看完这段时间内的行程；播放结束后保留完整路线供查看。

### 2.4 成功信号

| ID | 可观察信号 | 判定方式 |
|---|---|---|
| O001 | 入口在拉新记录下一项，每人都有正确绑定的轨迹展示操作 | 导航与逐行操作 |
| O002 | 单日、7日、30日及更长范围均合计10秒内完成一次全程回放 | 时钟测量与结果段/点集合核对 |
| O003 | 姓名、租户、日期与路线对应，跨日和断轨没有虚构连接 | 切人切范围及地图人工检查 |

## 5. 用户场景与验收

### US01 — 从管理页找到扫街人

#### AC-R001-01 — 导航和菜单登记一致
- Given Q001最终批准的租户范围及未自行排序的菜单。
- When 展开数据展示、进入扫街轨迹并查看menu/allMenu。
- Then 有拉新记录的医美租户在其下一项显示扫街轨迹；无旧入口的医美租户在数据展示中新增扫街轨迹，同一稳定route只登记一次，页签和内容一致；非医美租户不借平台定义获得入口。

#### AC-R001-02 — 已有菜单设置保留
- Given 已存在租户自定义排序、隐藏、父级限制及原权限。
- When 登记新入口、隐藏/恢复该入口或重开Shell。
- Then 原配置不重置，按068使用有效树；隐藏后直达不能绕过原限制；只影响本租户。

#### AC-R002-01 — 每个人对应自己的轨迹
- Given 当前租户多名扫街角色人员，含同名不同ID和没有轨迹的人。
- When 搜索姓名、分页并分别点轨迹展示。
- Then 每行都有操作，打开对应稳定人员ID；无轨迹人员仍在列表中，不以其没有定位记录推断未工作。

### US02 — 按日期快速看完整行程

#### AC-R003-01 — 日期范围与草稿生效
- Given 默认今天，人员列表与弹窗内各有日期范围控制。
- When 选择同一天、7天、30天或更长范围并点查询。
- Then 按北京时间开始日00:00至结束日次日00:00之前筛选；不人为限制跨度；弹窗生效范围同步回页面，尚未查询的草稿不更改当前结果。

#### AC-R003-02 — 非法或取消输入
- Given 已有成功查询结果。
- When 输入缺失日期或开始晚于结束，或展开日历后取消。
- Then 非法输入明确提示且不能提交，取消恢复生效日期；不启动新回放、不把旧结果标成新范围。

#### AC-R004-01 — 打开地图自动回放
- Given 某人有效范围含两点以上的移动行程。
- When 点该行轨迹展示。
- Then 大弹窗展示人员、日期、地图和起终点，视野容纳全部片段；路线逐步绘制，移动标记沿当前片段走，当前记录时间和进度随之更新。

#### AC-R005-01 — 日期跨度不延长总播放
- Given 含全部有效点的单日、7日、30日、365日以及高密度合成结果。
- When 分别开始一次回放，保持页面前台且不中断。
- Then 从动画开始至完成不超过10000ms；所有有效片段纳入同一时间轴，最终线条覆盖全部有效点，停在最后有效点；不得只取一天、截断后半程或逐段各播10秒。

#### AC-R005-02 — 结束与重播
- Given 一次回放完成，或回放中页面短暂失焦。
- When 等待或点重新播放；或稍后回到页面。
- Then 完成后保留完整路线并显示已播放完成，不自动循环；重播从首点重新计时且仍合计10秒内；失焦不能让逐点定时器积压并延长时间轴，回到页面按已过去时间恢复到正确进度或终态。

#### AC-R006-01 — 跨日和断轨不伪连
- Given 两天的行程及同一天两个明确断开的segmentId。
- When 动态回放到片段边界并查看最终路线。
- Then 按时间先后依次呈现，跨日或断点不画连接线，移动标记直接切换下一段起点并更新日期/时间；不沿不存在的跨段直线运动。

### US03 — 无数据、切换和异常后能恢复

#### AC-R007-01 — 无点与只有一个点
- Given 某范围无有效点，或只有一个有效点。
- When 查询或打开地图。
- Then 无点显示该日期范围暂无轨迹并清空旧线、禁用重播；单点显示位置和时间及仅有一个轨迹点，无移动假象；多段各只有单点也不生成连接线。

#### AC-R007-02 — 加载或数据错误
- Given 本地读取模拟失败、无效坐标/时间或地图初始化失败。
- When 打开或查询并重试。
- Then 加载、错误与确认空态分开；错误有重试入口且不播放旧结果；部分坏点排除并注明部分记录无法展示，在坏点处断开而不跨缺失点连线；全部无效显示记录无法展示。

#### AC-R008-01 — 中断不会出现旧人员路线
- Given A正在播放。
- When 关闭、切页签、切租户、切到B，或应用一个新日期范围。
- Then 立即终止旧动画/旧读取回调；旧结果不能覆盖新上下文；返回列表保留已生效日期/姓名搜索；重开时重新查有效结果并从头播放。

#### AC-R009-01 — 静态演示与访问隔离
- Given 两租户同名人员、未知人员/租户及模拟无权上下文。
- When 分别访问页面或伪造人员参数，并检查网络与浏览器权限请求。
- Then 只显示当前允许范围的合成数据，未知/无权不回退深圳或首人；无真实定位、地图API、上传或共享保存；页面明确轨迹为演示数据，原APP页面与DR责任分工不变。

### 7.3 进入、退出与恢复

- 关闭按钮、Escape关闭弹窗，焦点回原行操作；遮罩点击不自动关闭，避免误触。
- 弹窗未提交的日期草稿在关闭时丢弃；已查询范围在本页面会话保留。
- 快速重复点击操作只保留一个弹窗与一轮有效回放；刷新回到默认今天和未选人员。
- 页面失焦按实际经过时间更新回放；关闭/换上下文则取消，不在后台继续运行。
