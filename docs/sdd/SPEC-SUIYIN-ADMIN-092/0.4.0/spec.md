# 工作号每日质检：标准 AI Task 重做合同

2026-10-30最新实施增补：[上线样本纠正Plan／AC](live-corrections-20261030.md)，优先于先前说明中与本轮冲突的采集完成、诊断和复核展示。源候选仍待正式审阅。

本稿承接2026-10-29陈宣宇确认的完整方案及“那就开始做”实施授权。`proposed`表示源仓正式合入及团队知识库决策仍待审，不表示本轮用户未批准实施，也不伪称房总已经批准新DR。已确认范围按[完整Plan／AC](plan.md)执行，六条AC及验证矩阵是唯一详细验收定义，不再复制一套容易漂移的条件。

- 面向全部企业，企业数据库和当前工作号权限隔离；企微／个微各有日报入口，以工作号×自然日为身份，不改成沟通进度报告。
- 既有Prompt列表、正文、模型绑定和保存保留，仅移除两日报模板的高级草稿／试跑／发布。既有模板`cronEnabled`是唯一自动开关。每天04:00处理前一自然日，08:00是待容量验证目标；启用渠道覆盖当时已接入可分析工作号。
- 规则与指标独立页只有统计指标、质检维度、判定参数、产品目录。判定／数值／单枚举事实及指标可动态配置；指标拖动排序。显示修改立即生效，纯统计变化重算，新增语义另行分析，历史不被新规则覆盖。
- 七模块、日期／部门／工作号筛选、右侧只读原文及证据定位、意向与问题人工复核保留。AI原判、当前有效值和处理状态分别表达；严重程度不自动等同红线，未知不当零。
- 公共AI Task、托管DeepSeek、批次、Setting、限流及用量链路复用；新增日报、会话、事实、复核、统计五集合。复核后按受影响工作号当天重算，不预建逐指标增量平台。可靠记账、幂等、快照、接受版本和统计一致性属于当前必要范围。
- 删除旧日报独有worker／调用／重试分支、深圳限制、高级设置接口、六旧集合及自建索引入口；公共修复按消费者保留，不整体revert。旧日报数据不迁移，不做兼容；实际生产删除另行授权。
- 首版单聊，使用文本与已有语音转写；图片／视频识别、群聊、任意脚本／多选／嵌套类型、独立分析库及通用工作流不预建。

工程接口细化见[API合同](api-contract.md)，前后端按同一Scope／ReportRef及版本冲突行为实现。实施关联：[Go #5055](https://github.com/PetWebOrg/suiyin-go/issues/5055)、[Admin #606](https://github.com/PetWebOrg/suiyin-admin/issues/606)。
