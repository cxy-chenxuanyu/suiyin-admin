# 日报可靠性与运营操作调整（2026-10-30）

状态：本会话陈宣宇已确认完整Plan/AC并授权实施；源仓正式审阅仍为proposed。范围为Go#5109、Admin#621，取代0.4.0中与本补充冲突的展示和合同说明，其余约束保留。不修改历史0.3.x，不把原型演示说成生产已验。

## 操作和版式
沿现有管理页组件、字号、颜色、四类配置、七页签和右侧只读原文抽屉，不新增配置平台。运营路径：概览→需关注的工作号/客户→问题和原文→复核/跟进→返回原筛选、分页和位置。

规则页四组为「检查项目与标准」「日报展示指标」「回复与互动标准」「产品目录」。用户只填写业务名称、问题成立条件、适用范围/例外、严重程度及独立红线条件；通用真假/未知/证据字段约束由程序统一追加，不混进业务标准。默认显示简要标准，完整内容在编辑面板查看，避免表格中重复展开长段落。技术标识自动生成并稳定保留，枚举以可读选项编辑。旧租户业务标准只展示、人工确认后修改，不用正则批量截断或自动迁写。

指标只提供来源支持的统计方式，显示计算方式/分母/示例及统计单位，区分问题次数与涉及会话数。卡片开关与拖动顺序保留；隐藏报表指标不等于停止分析，停用检查项目作用于新分析。新增/删除支持的判断、数值、单选项目与指标无需改代码、部署或手改Prompt；新算法、新来源、嵌套/多选类型不在现有支持范围。

保存必须真实提交且重读一致，失败保留草稿；不出现让人误当已保存的多层「应用」成功。显示变化立即生效；确定性统计可重算不调用模型；新业务判定仅作用于新分析，历史保留当时标准，付费重新分析要沿现有管理权限和明确范围操作。

概览优先问题、待核实红线、未解决诉求及重点客户；状态说明真实完成/未分析/跳过/暂停/失败/等待。账号总数、参与本批次账号、可查看历史账号不混作一个分母。意向显示业务级别与理由、项目/时间和优先级；问题展示严重程度、证据、人工复核和跟进；红线候选/已认定/已排除独立；产品与老带新明确谁提及、出现次数/会话数；质检标准明确本份日报使用的历史版本。生成记录默认业务阶段、进度、原因和可执行操作，技术ID/错误码/调用诊断折叠并受原权限控制。

原文保留客户左/工作号右，头像缺失占位，昵称、时间和证据高亮清楚；正常消息不逐条显示「文本」「成功」「已解析」。只显示影响理解的失败/撤回/未转写/未识别等异常。媒体保持类型和已有可读转写/元信息，不增加识别、付费转写或读取当前聊天替换冻结原文。实际操作人只有可靠稳定身份匹配才展示，缺失不猜个人责任。关闭/Esc/遮罩恢复原位置。AI原判、人工结论、红线认定、跟进处理和消息来源状态独立。

「质检规则与指标」沿原企业菜单同步机制进入AI管理；两日报仍在聊天管理。企微/个微进入规则后保存/返回都回原渠道；冷启动直达不绕权限。提示词库保持原样，唯一两个cronEnabled开关保留，不新增自动生成页、高级发布或试跑流程。

## 后端合同
冻结启用定义驱动同一事实描述：code/kind/definitionVersion/value类型/数值上下界精度/启用选项/严重度/独立红线/产品ID。Schema与ValidateAnalysis不得分别维护矛盾规则。固定unresolved/product_mention/referral/highlight/suggestion仍为布尔判断，字段层级明确；未知/不适用不夹带确定值，可不引用不可读消息。

用户输入按当前分段给出可用事实证据、可用客户意向证据、只供上下文参考、不可读记录的边界；意向仅统计日客户可读消息。未识别图片/视频/表情仍是客户消息存在性，不可用来证明已理解内容。纠错返回受控路径、代码、期望及引用拒绝原因，不导出客户原文。每阶段总请求上限2次含纠错，公共AI Task/限流/快照/回执/用量/未知隔离与重放机制继续复用。

配置保存及分析派发前校验依赖、类型、参数、产品与统计支持；不满足时不发付费请求。暂停写入与汇总通过已有dataVersion/reviewVersion及状态围栏避免旧状态覆盖，实际无等待任务不能显示等待额度，已入队允许按原快照结束。现有五集合与Setting/Prompt保持，无新表、队列、钱包或规则执行平台。

Evidence响应新增可选presentation：`{customer:{name:string,avatar?:string},workAccount:{name:string,avatar?:string},operators:Record<string,{name:string,avatar?:string}>}`。这是当前可见显示资料，冻结messages、证据ID/时间/方向/正文保持权威。operators只以冻结actualOperatorId稳定匹配，缺失不猜。只在原账号ACL/结果版本验证后批量读取企业内既有实体，禁止逐消息查询、跨企业回退或返回整份客户资料。

## 同范围身份显示与派发预算细化
复核记录actor保存的是稳定用户ID，不是姓名。presentation可增加reviewers?:Record<string,{name:string,avatar?:string}>，仅按本次已授权返回的reviews.actor解析ObjectID后，在既有同一次users批量查询按_id匹配；不混进消息operators，不推断历史操作人或当前工作号责任，缺失显示复核人信息待核实，原actor仅授权诊断查看。RunRow.workAccountName直接使用报告名称。
启用的选项型检查至少保留一个启用选项，保存及派发前共用校验拒绝全停用；停用整个定义保留历史合法。日报每阶段上限2次是实际已派发请求，包含供应商401/429与结构纠错；本地配额探测不消耗请求数，已有响应/回执恢复不重发。仅日报执行这项业务预算，非日报公共等待和额度策略保持原样。
