# 日报风险结果与资料缺口分离

2026-11-01用户确认：针对已确认问题快速调整，准备开启任务。修正默认上游完整性状态阻断正常风险判断的问题，区分未发现问题与已有一般问题；不增加媒体识别、规则引擎或新配置。

正常取数完成只设置captureComplete=true，collectionComplete继续如实表达上游完整性，不能伪改true。风险根据已接受的相关检查事实判断，不以不可证明的上游完整性或任意媒体占位一刀切降unknown。

## 分类与合同

- none：分析完成、参与风险判断的适用检查具备明确结论，未发现问题或未解决诉求；运营显示“未发现问题”，限定为本次已检查内容。
- low：确有一般问题但未达中风险；显示“一般问题”，不能把它也称为无问题。
- medium/high：保留原标准；至少一项严重问题为high，至少两项一般问题或存在未解决诉求为medium。有证据的高/中风险不被其他未知项掩盖。
- unknown：未有有效分析，或相关风险检查尚无可用结论；全部不适用、没有可评估风险检查也不冒称已经确认无问题。普通数值/枚举、产品、亮点不参与风险充分性；固定unresolved仅在输出时按其状态判断，不为可选观察的缺省伪造结论。

风险枚举扩展为none/low/medium/high/unknown，Overview分布、过滤、列表、统计与原AI/复核后口径一致，none/low互斥，分布总数仍等于已分析数。ConversationRow可追加安全riskReason，解释哪些相关检查未知；详细理由复用现有事实原文抽屉，不另建流程。资料缺口单独提示，不覆盖有效判断，不承诺绝对无风险。

新生成、人工复核及本地重算复用同一分类。已有报告通过明确的本地统计重算刷新派生风险与投影；原AI事实、复核事实保留，两个口径分别计算。不自动扫写生产、不调用模型。未重算旧unknown不武断改none；旧low可按现有明确问题数做读侧兼容。

## 验收标准

- AC-1 Given真实采集起步的纯文字、双方5+5、有效分析且相关检查明确无问题，When生成与汇总，Then none可达，captureComplete=true、collectionComplete=false不阻断结论，不伪造源端完整。
- AC-2 Given不影响明确结论的未识别媒体、相关检查unknown、全部不适用或无适用风险检查，When汇总，Then前者正常分级并提示资料缺口，后者保留unknown及可理解原因；已证实高/中风险保留。
- AC-3 Given零问题、单一般、多一般、严重与未解决诉求，When原AI/有效结果的概览、过滤及下钻，Then五类互斥、计数与名单一致，未分析不混入分布，动态检查不逐项改代码。
- AC-4 Given已有结果、人工复核、统计并发或重复操作，When明确本地重算，Then只更新对应修订的派生风险及统计，事实/复核不丢失、不重复计数、模型调用0，读页面不写库。
