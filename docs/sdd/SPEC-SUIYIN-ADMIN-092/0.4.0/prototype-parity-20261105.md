## 范围与已确认决定

- 5B：员工主动只计员工先引入同一品项；客户先问后的回应仍计普通触达。缺有效上下文标未知。单品和跨品项分别按会话去重，触达占比以全部质检会话为分母。老带新已触达与未铺垫用现有独立事实。品项目录沿企业现有配置。
