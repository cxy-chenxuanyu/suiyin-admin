企微、个微是聊天管理下的两个独立页面；提示词库及企业模型目录仍属AI管理。当前深圳真实视图只读展示2026-10-19／20已保存报告，不显示本地功能执行面板。模块来源为`admin-quality-report.js/.css`，当前行为以[PRD](../prd/chat-quality-daily.md)及[流程](../flowcharts/chat-quality-daily.md)为准。

| 区域 | 当前设计与边界 |
| --- | --- |
| 版心 | 1180px最大宽，内留白22px／18px／60px；浅灰背景，白卡12px圆角；中文字体沿南京参考，普通字号14px、表格13px |
| 颜色 | 主色沿碎银`--primary`青绿，选中页签及强调线同色；红橙风险状态、紫色角色标识保留，不能因统一主色削弱风险区别 |

| 导航顺序 | 标题／摘要之后先七页签，再展示当前页卡片与列表；七页签粘附顶部，顺序为概览、意向、员工、问题、红线、大单品与老带新、标准 |
| 概览 | 六个KPI卡与洞察卡，单位、分母、候选／确认及未知各自明确；数字来自保存结果或确定性聚合 |
| 意向 | 五档意向卡，客户名单按人设工作号分组，含工作号下拉、名单搜索及一级／二级筛选；未判定保持未知，不依据员工推销提升意向 |

| 问题与红线 | 同文案保留覆盖会话，逐occurrence打开对应证据；候选不冒充人工定责。维度证据不足可与原结论状态重叠，说明计数口径 |
| 筛选 | 工作号下拉与搜索位于相应客户／问题／业务名单；不将名单筛选误称跨七模块的全局筛选。其他报告日期、渠道和本地状态不串用 |
| 来源说明 | 页尾可展开来源、统计与语义覆盖、媒体缺失、观察截至及合成示例入口；显示更新不改变原分析生成时间 |

原文从右贴边抽屉滑出，桌面验收宽760px，窄屏不溢出视口；它不是居中对话框。消息区复用PC只读布局，客户左、我方右，昵称／头像／时间／来源按可得字段显示，头像可占位，缺失来源、状态与实际操作人用unknown。消息按同会话稳定seq／时间排列，问题高亮定位其自身证据，关联多个会话时切换定位对象；无客户间证据混用。AI摘要单独标“非原话”，不放进原消息气泡。

消息媒体仅显示本机已取得的信息：语音可展开已有转写，没有音频源时无播放按钮；未OCR图片、未转写语音和空正文不补造内容。抽屉只读，无输入框、发送、转发或撤回。关闭按钮／Esc／遮罩关闭后恢复原页签、名单状态、滚动和入口焦点，清除临时样式；长时间轴独立滚动。

AI提示词页面保留原列表标题、全部场景筛选、六列表头和右下分页。两条日报模板与普通行共同使用`apt-row-actions`的编辑／删除文案、样式和排列；取消“查看企微日报／查看个微日报”操作。基础字段遵循采样顺序：场景、适用时的填写标签、定时、绑定模型、模板名、正文；标签为可搜索多选下拉，标签场景正文名为“主要提示词”。分组子提示词按分组折叠，展开显示权限分组与完整子正文。新日报草稿／试跑／发布保留在高级区，共用规则从工具栏进入，均明确本地演示。

删除先说明目标渠道与本地影响，确认持久化成功后才隐藏并停用；取消与失败保留原行、启用状态和配置。历史报告、另一渠道、共用规则、模型及正文／版本备份不变，无新增恢复重建流程。模型页保持来源／名称／供应商／接口地址／场景／是否启用六列只读，调用配置由平台维护。

完整Prompt、真实名称、聊天原文及侧车仅本机私有，公开材料只保留代码、合成示例和安全摘要。公开quality-public-demo.json从旧合成fixture生成四报告，installPublic校验后使用同一新版日报与抽屉，明确合成／无实际AI；本机优先私有，只有404回退公开合成，其他错误不掩盖。未取得真实数据不能标采集完成，不借其他租户填充；北京实采0条与两家入口不可用分开。API暂停和04:00至08:00未实测状态保持，静态通过不等于生产运行。旧版式回执与旧0.3.x截图仅作历史，详见[来源收敛](sdd/SPEC-SUIYIN-ADMIN-092/0.3.3/source-convergence.md)。

## 证据与适用范围

当前导航登记17租户、822个页面入口、91种路由；源队列783个入口中741可见页已采、42保持源隐藏。原型扩展包含13个已有AI管理父级租户的AI费用统计、6个现有艺星回访规则和6个辅助线管理，另有画美/傲丽各3个待采集原型入口，以及本轮8个医美扫街轨迹原型入口，均不计入实站采集；工具管理是结构父级，不计业务路由。2026-09-18 保存的 UI 资料覆盖 61 种路由、19 种编辑弹窗、2 种整页编辑；65 个菜单名称、64 个按钮名称拥有 SVG 映射，这些数量不是唯一图形数，也不表示所有租户已采集。

结构以本租户本路由的原始采集为先，其次使用明确标识的参考结构。`data/live-ui-reference.js` 提供来源几何，`data/form-schemas.js` 保留安全表单结构，`data/button-states.js` 提供采集按钮状态，专用模块保留各页面语义。不能因为存在共用 CSS 就推断所有路由颜色、字段、排列或交互相同。
